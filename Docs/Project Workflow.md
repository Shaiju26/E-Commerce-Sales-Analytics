# Project Workflow

## E-Commerce Sales Analytics

This project follows an end-to-end data analytics workflow, starting from raw data preparation and ending with business insights and interactive visualization.

---

## 1. Data Collection

The project uses e-commerce sales data containing information about:

- Sales transactions
- Customers
- Products
- Promotions
- Discounts
- Orders

The original data was provided in Excel format.

---

## 2. Data Cleaning

The raw data was reviewed and prepared for analysis.

Key activities included:

- Checking missing values
- Checking duplicate records
- Reviewing data types
- Validating sales and profit values
- Checking date fields
- Reviewing categorical values
- Identifying potential data quality issues

---
